# Security Policy

## Supported Versions

Pulse Analytics Group LLC actively maintains the latest version of this website and its associated source code.

Security updates are provided for the current version hosted in this repository. Older versions, forks, or archived copies are not supported.

| Version | Supported |
|---------|-----------|
| Current | ✅ |
| Previous Releases | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability affecting the Pulse Analytics website, please report it privately.

### Contact

Email: **pulseanalyticsgroupllc@gmail.com**

### Please Include

- A description of the vulnerability
- Steps to reproduce the issue
- The affected page(s) or feature(s)
- Screenshots or proof of concept, if applicable
- Any recommendations for remediation

### Response Timeline

We strive to:

- Acknowledge reports within **3 business days**
- Investigate reported vulnerabilities promptly
- Provide status updates during the investigation
- Release a fix as quickly as practical based on the severity of the issue

We appreciate responsible disclosure and ask that vulnerabilities not be publicly disclosed until they have been investigated and resolved.
